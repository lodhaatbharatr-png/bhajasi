# भजासी

**संतवाणी • अभंग • हरिनाम • चिंतन**

`bhajasi` is a mobile-first Marathi Sant Sahitya reader. It presents each selected line together with a simple meaning, with day-wise reading navigation and a separate Sant catalog.

## Design principles

- Minimal, calm mobile UI
- Devanagari-first typography
- Original text separated from explanation
- Data-driven content in `data/saints.json`
- Easy expansion to additional saints and works
- Day-wise reading support
- Share and responsive navigation

## Content note

The repository currently contains a small starter dataset to demonstrate the reader. Before publishing a complete library, source texts should be checked against reliable editions and edition-specific पाठभेद should be recorded where relevant. Meanings are explanatory summaries, not substitutes for scholarly commentary.

## GitHub Pages

The site is configured to deploy through GitHub Actions. In the repository settings, set **Pages → Source → GitHub Actions** if Pages has not already been enabled for the repository.
